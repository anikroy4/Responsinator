# Contributing

Thanks for your interest in contributing to Responsinator — small, focused contributions are greatly appreciated.

How to contribute

1. Fork the repository and create a feature branch from `main`.
2. Keep changes focused and well-scoped.
3. Run the linter and ensure formatting matches the project.
4. Open a pull request describing the intent and scope of your change.

PR checklist

- [ ] Changes are limited to a single purpose
- [ ] Code builds and runs locally
- [ ] No TypeScript/ESLint errors introduced (run `npm run lint`)
- [ ] New features include basic documentation or examples in the README
- [ ] Tests added for bug fixes or new behavior when applicable
- [ ] Commit messages are descriptive and reference any related issues

Review process

PRs will be reviewed for clarity, correctness, and alignment with the project's minimal design. Maintainers may request small changes before merging.

Thank you for helping improve Responsinator!
